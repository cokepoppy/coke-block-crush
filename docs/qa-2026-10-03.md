## 自动反馈回归补充

本轮新增 `npm run test:feedback`：先跑引擎单测和生产构建，再用 Playwright 在 `390 × 844` Chromium 视口执行浏览器回归。自动检查 Level 1/4/7 稳定帧、实现截图基线、可见控件放置、重叠无效输入、重开状态、清行与苹果计数、光束/飞行动画挂载及结束清理；运行时监控页面异常、非预期 HTTP 错误和资源请求失败。浏览器音频检查确认首次用户操作前未创建 AudioContext，操作后 Web Audio 进入 running 状态且确实排程音乐声部、接受按钮/落块/清除/收集提示音，并验证音乐和音效开关会影响对应信号路径。

同一 Level 1 参考图裁切 `575 × 833` 并缩放到游戏视口后，使用 `pixelmatch` 阈值 `0.16` 做像素差分；遮罩视频中央播放键 `105 × 110`（11,550 像素），测得差异 **6.54%**。此数值是当前不同截图来源及裁切映射下的度量，不是像素级通过；差分图、叠图、实际图和 JSON 报告保存在被 Git 忽略的 `test-results/feedback/`。Playwright 三张提交的 PNG 是本地实现回归基线，和源游戏参考帧分开保存；更新本地实现基线不会被当作源图匹配证明。

音频自动化测量的是 Web Audio 启动、排程与 cue 接受情况，不会从浏览器硬件回环录音，也不判断音色、响度、旋律或循环接缝。因此，声音行为的自动回归已接入，原作音乐/音效的一致性仍需取得带原声参考并做听辨/波形比对。

自动验收命令与结果：`npm run test:feedback` 通过（10 项单测、Vite 构建、5 项 Playwright 用例）；参考图差分门禁用 `BLOCK_CRUSH_MAX_DIFF_RATIO=0.08` 单独重跑并通过，结果为 6.54%；Skill Creator `quick_validate.py` 返回 `Skill is valid!`。`git diff --check` 在提交前另行执行。该差分只代表当前裁切与遮罩配置下未超过 8% 门槛，不代表零差异或像素级通过。
